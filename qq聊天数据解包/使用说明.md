# 使用说明（操作手册）

> 本手册面向：拿到一个 QQ NT 备份（.bak）或需要解密本机 QQ 数据库的人，按步骤复现"解密 → 导出 → 统计 → 人设卡"全流程。
> 配套总览与逻辑说明见同目录 `README.md`；密钥材料不在本目录（见安全提醒）。
> 所有脚本无命令行参数，直接改脚本内常量后运行：`C:\Users\20535\miniconda3\python.exe xxx.py`。

## 二、阶段 1：获取密钥

**目标**：从 QQ 进程内存拿到本机库的 AES 密钥 + salt，写入 keys.txt。

### 步骤
1. 确认 QQ 已登录且在运行（密钥字符串只存在于运行中进程的内存）。
2. 编辑 `qkey.py` / `verify_all.py`：
   - 确认 `keys.txt` 路径、进程名（QQ.exe）；
   - `verify_all.py` 顶部 **必须** `from qqdec import scan_pid_for_salts`（缺导入会表现为扫描假失败）。
3. 运行：
```powershell
& 'C:\Users\20535\miniconda3\python.exe' '.\verify_all.py'
```
4. 预期输出：本机 3 个库逐一报告密钥命中（HMAC OK）；bak 4 库 salt 如不匹配属正常（见 README 三节）。
5. 产物：`keys.txt`（每行 `库标识,密钥hex,salthex`）。**此文件敏感，勿外传。**

---

## 三、阶段 2：解密本机库

**目标**：把加密的 nt_msg.db 解成可读明文 SQLite。

### 步骤
1. 编辑 `test_decrypt2.py`：
   - 把 `KEY = bytes.fromhex('<数据库密钥，从临时目录 keys.txt 读取，勿外传>')` 替换为 keys.txt 里的密钥 hex；
   - 确认 `SRC`（本机 nt_msg.db 路径）、`DST`（输出路径）正确。
2. 运行：
```powershell
& 'C:\Users\20535\miniconda3\python.exe' '.\test_decrypt2.py'
```
3. **必须验证**（不能只看文件生成）：
```powershell
& 'C:\Users\20535\miniconda3\python.exe' '.\integrity_check.py'
```
4. 预期：`PRAGMA quick_check` 仅剩无害 freelist 警告；32 张表可读。

### 关键参数（不要改错，见 README 三节）
- `EXT_HEADER=1024`、`PAGE_SIZE=4096`、`RESERVE=48`
- 明文 header 的"每页保留字节"（offset 20）必须写 **48**，不能写 0 或 80。

## 四、阶段 3：探查与导出消息

**目标**：定位坏行范围，导出目标会话全部消息为 `conv.json`。

### 步骤
1. 定位坏行（解密库有约 222 行因 freelist 页碎片损坏）：
```powershell
& 'C:\Users\20535\miniconda3\python.exe' '.\probe_blob3.py'
```
2. 确认目标会话：编辑 `export_conv2.py` 里的会话 UID（`u_VjGLU3TISJx5yA4_aT7mSQ`）与库路径。
3. 导出：
```powershell
& 'C:\Users\20535\miniconda3\python.exe' '.\export_conv2.py'
```
4. 预期产物：`conv.json`，字段 `id / self / sender_num / type / sub / time / els[{t,text}]`；本次 41,085 条（缺失 222 / 0.5%，自动跳过坏行）。

### 说明
- 若某会话的 `40030` 列在坏行上抛 `malformed`，是坏行所致，按主键分块 + skip 即可（脚本已内置）。
- 需要先确认会话分布时运行 `identify_sessions2.py`。

- **通知 ≠ 发言**：撤回/入群/戳一戳等系统通知文本必须剔除，否则口头禅与标点数字严重失真（实测感叹号从 718 修正为 24）。

## 八、常见错误与故障排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `ModuleNotFoundError: cryptography` | 用了系统默认 python | 改用 `C:\Users\20535\miniconda3\python.exe` |
| `scan_pid_for_salts` 未定义 / 扫描假失败 | verify_all.py 缺 import | 补 `from qqdec import scan_pid_for_salts` |
| quick_check 报大量 cell 错误 | header reserved 写错（0 或 80） | 改为 48 后重解 |
| 页不对齐 / 全库错位 | 非首页只输出 4048 | 每页补齐 4096 |
| `40030 malformed` 异常 | 坏行（约 222 行） | 按主键分块 + skip，勿改全量策略 |
| 戳一戳归属看起来全是对方 | 用了 40020 字段 | 改按通知文本首个 `<qq uin>` 判定 |
| bak 4 库 HMAC 全不匹配 | 离线解密此路不通 | 走"bak 已导入本机"路线（README 九节步骤 5） |
| 中文乱码 | 脚本/终端编码 | 脚本顶部 `# -*- coding: utf-8 -*-`；输出用 UTF-8 |
